# 覆盖维度 Checklist（9 维度）

每个功能点产出用例后，**逐项核对**以下 9 个维度。每条用例标题前必须含对应维度标识。

## 维度 1：正常流程

- 主流程：从入口到完成的标准成功路径
- 次要流程：可选分支、不同入口
- 典型角色下的成功路径
- 标准数据下的成功路径

**用例标识**：`[正常流]`

## 维度 2：异常场景

- 流程逆向（如：未登录直接访问、未付款直接收货）
- 操作错误（点击错按钮、跳过必填项）
- 状态非法跳转（已支付订单再次支付）
- 取消、回退、关闭对流程的影响

**用例标识**：`[异常]`

## 维度 3：边界值

每个数值/长度字段必须覆盖（共 6 点）：
- min-1（无效下边界）
- min（有效下边界）
- min+1（有效下边界邻近）
- max-1（有效上边界邻近）
- max（有效上边界）
- max+1（无效上边界）

时间类字段：
- 起止时间相等
- 起 > 止
- 跨日 / 跨月 / 跨年 / 跨时区
- 闰年 2 月 29 日
- 夏令时切换

**用例标识**：`[边界值]`

## 维度 4：空值

区分以下 4 种「空」：
- 字段未传（缺失）
- 字段值为 null
- 字段值为空字符串 `""`
- 字段值为空数组 / 空对象 `[] / {}`

必填字段空与非必填字段空，预期不同，需分别建用例。

**用例标识**：`[空值]`

## 维度 5：特殊字符

- emoji（含组合 emoji）
- 空白字符（空格、Tab、换行、零宽字符 ZWSP）
- 引号（单引号、双引号、反引号）
- 转义字符（`\n` `\t` `\\`）
- HTML / JS（`<script>` `<img onerror>`）—— XSS
- SQL 关键字（`' OR '1'='1` `; DROP TABLE`）—— SQL 注入
- URL 编码（`%20` `%3C` `+`）
- 中英文混合、繁体、生僻字
- RTL 字符（阿拉伯文、希伯来文）
- 控制字符（0x00-0x1F）

**用例标识**：`[特殊字符]` 或叠加 `[XSS]` `[SQL注入]`

## 维度 6：权限校验

- 未登录访问需登录的功能
- Token 缺失 / 错误 / 过期 / 被吊销
- 横向越权：账号 A 通过修改 ID 访问账号 B 的资源
- 纵向越权：普通用户访问管理员接口
- 跨租户：租户 A 访问租户 B 的数据
- 角色降权后旧 Token 仍可访问
- 资源所有者校验（只能操作自己的订单/文章/文件）

**用例标识**：`[权限]` 或叠加 `[越权]`

## 维度 7：数据唯一性

- 重复创建（相同唯一字段二次提交）
- 并发创建（同一时刻两次提交）
- 软删后重建（已逻辑删除的数据再创建同名）
- 跨租户同名（不同租户允许重名）
- 大小写敏感性（如「Admin」与「admin」是否同义）
- 前后空格、全半角、Unicode 同形异码（如俄文 `а` vs 英文 `a`）

**用例标识**：`[唯一性]`

## 维度 8：重复操作

- 重复点击同一按钮（防抖、节流）
- 重复提交同一表单（幂等性）
- 网络抖动后重试
- 浏览器后退/前进重放请求

**用例标识**：`[重复]`

## 维度 9：异常输入

- 类型不匹配（string 传 int、int 传 object）
- 格式错误（邮箱无 @、手机号位数错、日期非 ISO）
- 协议错误（URL 无 scheme、JSON 不合法）
- 枚举外值（未定义的状态/类型）
- 参数大小写敏感性

**用例标识**：`[异常输入]`

## 自检矩阵（输出末尾必附）

| 功能点 \ 维度 | 1 正常流 | 2 异常 | 3 边界 | 4 空值 | 5 特殊字符 | 6 权限 | 7 唯一性 | 8 重复 | 9 异常输入 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|
| 功能点 A | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | — | ✓ | ✓ | 唯一性不适用 |
| 功能点 B | ✓ | ✓ | N/A | ✓ | — | ✓ | ✓ | — | ✓ | 边界 N/A；特殊字符/重复待补 |

- ✓：已覆盖
- —：未覆盖（需在备注中说明原因）
- N/A：不适用（需在备注中说明原因）

**任何 — 必须在备注中说明原因**，不允许沉默跳过。
